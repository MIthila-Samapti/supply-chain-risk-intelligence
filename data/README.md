# Data

This project builds directly on the daily sales panel produced by the
[retail-demand-forecasting](https://github.com/MIthila-Samapti/retail-demand-forecasting)
project: `data/processed/daily_sales_by_store_family.csv` (10 stores x 8
product families, with promotion, holiday, and oil-price context already
attached).

No new raw data download is required to reproduce Phase 1 and Phase 2 of
this project. If external volatility/logistics-cost data is added later, it
will be documented here with its source and download steps.
